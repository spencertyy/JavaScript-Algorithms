# ⭐ JavaScript Algorithms

This repository contains a curated collection of **JavaScript algorithm implementations** written by me as part of my continuous learning and interview preparation.

The focus of this repo is not just on solving problems, but on **understanding the underlying logic, edge cases, and JavaScript-specific behaviors**, such as closures, `this` binding, async timing, and time/space trade-offs.

---

## ✨ What You’ll Find Here

- Hand-written solutions to classic algorithm problems in JavaScript  
- Common interview patterns:
  - Arrays & Strings  
  - Recursion  
  - Hashing  
  - Sorting  
  - Debounce / Throttle  
- Clear and readable code with an emphasis on **why** the solution works  
- Optimized approaches alongside simpler baseline solutions when applicable  

---

As a JavaScript / Frontend-focused developer, I believe strong fundamentals lead to better UI logic and system design.
